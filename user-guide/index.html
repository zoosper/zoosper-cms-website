User guide

Zoosper Admin provides authenticated workspaces for content and platform operations.

Pages

Create, edit, preview, publish and unpublish site-scoped pages. Pages support HTML output, Editor.js JSON and SEO metadata. Page revision history is under active 0.2 development.

Media

The Media library supports managed uploads and Editor.js image uploads. Derivative processing remains disabled until a production processor and enablement policy are configured.

Settings

The Settings workspace displays layered configuration by category and scope. Module defaults may be editable or read-only depending on ownership and source.

Sites and themes

Sites own domains, homepage configuration and theme assignment. Themes are assigned per site.

Administration

Admin Users, Roles and Permissions control access. Audit Log and Login History provide administrative and authentication records. Two-factor authentication is supported where configured.

Store Orders

Store Orders provides a remote Admin-grid workspace when its Node API endpoint is configured.
